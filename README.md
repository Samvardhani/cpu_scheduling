# CPU Scheduling Simulator

A web-based CPU Scheduling Simulator built as part of an Operating Systems mini-project. This tool is designed to help students and enthusiasts understand how various CPU scheduling algorithms work.

---

## 🚀 Features

- Visual simulation of CPU scheduling
- Supports multiple scheduling algorithms:
  - First-Come First-Serve (FCFS)
  - Shortest Job First (SJF)
  - Round Robin (RR)
  - Priority Scheduling
- Real-time calculation of:
  - Turn-Around Time (TAT)
  - Waiting Time (WT)
  - Gantt Chart visualization
- Clean and responsive UI using HTML, CSS, and JavaScript
